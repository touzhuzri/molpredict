# 杀菌剂-like 原理样机：一页说明

**目的**：向老师演示“数据 → 模型 → 网页打分 → 实验候选排序”的完整流程，
并说明当前瓶颈是真实活性数据和人工标注，而不是模型代码或算力。

## 做了什么

- 合并旧 PPDB 与新 D2.1 数据：3,100 个结构，其中 2,078 个可监督
  （726 正 / 1,352 负）；UNKNOWN 不当负样本，CONFLICT 不进入训练。
- 复刻 APPf 风格：24 个 PaDEL 描述符 + CatBoost + 25 个平衡子集。
- 扩展 demo 模型：再加入 12 个 RDKit 描述符 + Morgan/MACCS 指纹。
- scaffold split，3 个划分，测试集只做最终评估；阈值和校准只用验证集。
- 做了一个本地网页 demo：输入 SMILES / CSV / SDF，输出排序、阈值、适用域、
  SHAP 贡献和 25 个模型的分歧度。

## 关键证据

| 检查 | 结果 |
| --- | --- |
| APPf 风格 P24（24 PaDEL） | 测试 AUC **0.737 ± 0.062** |
| 扩展 demo EXT（PaDEL+指纹） | 测试 AUC **0.872 ± 0.018** |
| split 42 单次 EXT | AUC **0.853**（95% CI 0.809–0.892），PR-AUC 0.749，F1 0.730 |
| Top 10% 富集 | Precision **0.903**（31 个里 28 个正） |
| 旧数据训练 → 仅新数据正 | AUC **0.821 ± 0.025** |
| 50 次标签置换 | null 0.502 ± 0.049，观察 0.851，**p = 0.020** |
| 适用域（Tanimoto ≥0.30） | 覆盖 74.4%，域内 AUC **0.884**，域外 0.735 |

**解释**：模型在未见过的 scaffold 上有稳定排序信号，且不是随机标签造成的；
但这是“是否有杀菌剂用途/登记证据”的代理任务，不是杀菌活性。

## 不是什么

- 不是实测 MIC/EC50/抑制率；
- 不是对某个病原的活性概率；
- 不是田间防效；
- 没有真实外部实验盲测；
- 没有把 UNKNOWN 当阴性；
- 高分不等于实验一定命中。

## 现在缺什么

要把它从“原理样机”变成“可验证的活性模型”，需要：

1. **300–500 个化合物**，在同一实验条件下测试；
2. **3 个病原**：*Botrytis cinerea*、*Fusarium graminearum*、
   *Magnaporthe oryzae*；
3. **100–200 个明确无活性/弱活性**化合物；
4. **100 个盲测外部化合物**，不参与训练；
5. 历史筛选数据（包括失败化合物）优先；
6. 0.5–1 人 × 3 个月做数据整理/标签复核，0.5 人 × 3–6 个月做实验。

## 建议的下一步

1. 用 demo 对现有化合物库排序；
2. 选 Top 10–20% + 随机对照，送同一病原面板；
3. 用实验结果做 prospective validation；
4. 如果 Top-k 命中率显著高于随机对照，再扩大规模。
